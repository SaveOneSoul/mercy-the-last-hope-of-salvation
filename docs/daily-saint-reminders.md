# Daily featured saint reminders

The workflow `.github/workflows/daily-saint-reminder.yml` runs at approximately 08:00 India Standard Time each day (GitHub scheduled jobs can start late). It reads the featured directory in `pages/saints.html`. Manual workflow runs are **dry runs** and never publish. If no feast is listed for that date, it sends nothing.

WhatsApp delivery is limited to a mission-managed recipient who has opted in. Configure these repository secrets: `WHATSAPP_API_URL` (`https://graph.facebook.com/vXX.X/PHONE_NUMBER_ID/messages`), `WHATSAPP_ACCESS_TOKEN`, and `SAINT_REMINDER_WHATSAPP_RECIPIENT` (international number). Set repository variable `SAINT_REMINDER_WHATSAPP_TEMPLATE` to the name of a Meta-approved message template whose BODY has three text variables in this order: saint name, feast date, story URL. Optional variable `SAINT_REMINDER_WHATSAPP_LANGUAGE` defaults to `en_US`. The existing contact reply helper is **not** used for these daily messages: outside the 24-hour service window, a message template is required. Do not put tokens or phone numbers into repository files.

For a public Facebook **Page post**, configure secret `SAINT_REMINDER_FACEBOOK_PAGE_TOKEN` and variable `SAINT_REMINDER_FACEBOOK_PAGE_ID`. The token needs authorization to publish as that Page. Optional variable `SAINT_REMINDER_GRAPH_VERSION` defaults to `v23.0`; update it when your Meta app requires another supported version. This is a Page post, **not** a private Facebook message or notification to every follower. The workflow does not connect to a personal Facebook profile.

Each channel is skipped independently if its settings are absent. The job logs only the saint and delivery status; it never prints a token or recipient. To check selection safely, run `python scripts/daily_saint_reminder.py --dry-run --date 2026-10-05` locally, or use the manual GitHub workflow button. Do not repeatedly rerun a scheduled live job, as Meta may receive a duplicate post. The existing downloadable calendar remains an option for each visitor's own reminders without supplying a phone number.
