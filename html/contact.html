Prayer Requests & Contact

Send prayer requests, questions, testimonies and requests for a reply through the Mercy website.

Use this form for prayer requests, Catholic faith questions, testimonies, invitations, collaboration or requests for a reply. The static GitHub Pages version supports email/WhatsApp fallback after you add your contact details in javascript/config.js.

Privacy note: once a backend is added, publish a proper privacy policy, retention policy and consent notice before collecting personal data in a production database. Prayer requests can contain sensitive personal information.

Catholic-only AI replies

Mercy Guide boundary: The production AI is designed to answer only Roman Catholic faith, doctrine, Scripture in Catholic context, sacraments, prayer, saints, Divine Mercy, Catholic Charismatic Renewal and Catholic pastoral formation. Unrelated questions are refused, and doctrinal answers require approved Catholic source references.

Automatic replies

The floating Mercy Guide currently answers common questions from an offline JavaScript knowledge base. When a secure backend is deployed, set enableRemoteAI: true and apiBaseUrl in javascript/config.js. The browser will then call /api/chat without exposing the AI provider key.
